Deployment

Server

The server is a go application running on round.infra.ioscv.co.uk.

The deployment is handled by git pulling from the main branch, the docker image will then need to be rebuilt and restarted.

git pull
docker build ios-gridwatch
docker compose up -d

click here for more details on the server

Data

The data is sourced from Prometheus running on merrick.infra.ioscv.co.uk. This address can be configured via the approriate flag, along with any authorisation required.

Front End

The front end is hosted on cloudflare and is accessible at https://gridwatch.ioscv.co.uk.
