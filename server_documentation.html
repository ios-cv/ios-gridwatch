Deployment

Server

The server is a go application running, containerised on round.infra.ioscv.co.uk. nginx, also containerised, is used as a reverse proxy.

Environment variables are set in the gridwatch.env file in the gridwatch directory at the root of round.

Deployment is handled by git pulling from the main branch, the docker image will then need to be rebuilt and restarted.

cd ios-gridwatch git pull
docker compose build ios-gridwatch
docker compose down
docker compose up -d

The server exposes the following endpoints:

  • GET /sse - A server sent events stream
  • GET /site/:site/:period eg /site/porthmellon+Enterprise+Centre/7 - Returns site data for the previous 7 days for Porthmellon Enterprise Centre.
  • GET /site/all - Returns data for all sites
  • GET /setup - Returns basic data such as the number of sites and other values set by flags/environment variables like the declared net capacity.
  • GET /health - Returns 1 if the server is receiving data from the number of sites set using the GRIDWATCH_MONITORED_COUNT flag, 0 otherwise.
  • GET /energylocalday - Returns the sum of any increase in meter readings for any sites listed in the energy local flag in 30 minute intervals for the current day.
  • GET /energylocalinstant - Returns the sum of current active power for all sites listed in the energy local flag.

Data

The data is sourced from Prometheus running on merrick.infra.ioscv.co.uk. This address can be configured via the approriate flag, along with any authorisation required.

Front End

The front end is hosted on cloudflare and is accessible at https://ios-gridwatch.pages.dev. This uses automatically tracks changes to the github repo and serves the frontend in the dist folder.
