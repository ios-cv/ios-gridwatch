Flags

  • host
  • port
  • username for accessing prometheus server
  • password for accessing prometheus server
  • prometheus url
  • estimated net capacity the estimated net capacity of unmonitored sites
  • declared net capacity the total dnc of the monitored sites
  • site count the number of monitored sites
  • update time frequency of sse update messages

Endpoints

  • /health returns 1 if the prometheus server is providing data for <site count> sites, 0 otherwise configurable time for stale data
  • /setup returns json { "siteCount": number of sites actually responding from prometheus, "monitoredCount": <site count>, "dnc": <dnc>, "enc": <enc>, "updateTime": <update time> }
  • /sse sends json every <update time> seconds: { "total_kwh":the sum of export all monitored export meters, "day_kwh":the sum of any increase in export meters multiplied to estimate total production since midnight, "week_kwh":the sum of any increase in export meters multiplied to estimate total production in the last rolling week, "year_kwh":the sum of any increase in export meters multiplied to estimate total production in the last rolling year, "current_w":the sum of all sites current generation multiplied to estimate current generation for all of Scilly, "sites":[ { "name":The "site" label from Prometheus, "snapshot":the current watts this site is producing, "today":the total kWh this site has produced since midnight, "week":the total kWh this site has produced in the last 7 * 24hrs, "year":the total kWh this site has produced in the last 365 * 24hrs, "max":the highest watts this site has produced in the last 2 years }, { "name":"Unmonitored (estimated)" - estimates based on all monitored sites, "snapshot":the current watts, "today":the estimated kWh since midnight, "week":the estimated kWh in the last 7 * 24hrs, "year":the estimated kWh in the last 365 * 24hrs, "max":the estimated highest watts in the last 2 years } ] }
  • /site/:sitename|all/:period returns json:
  • /site/all
